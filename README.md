# The World Today — 19 November 2026

A program that draws a one-page newspaper summing up 19 November 2026 world news: the GTA VI global rollout leads, with a world-map strip and columns of real headlines from every region. It is written in pure Python 3.13 standard library and renders a deterministic 1024x1024 front page.

## Run it

```sh
python3 main.py
```

Running it writes `entry.png` (1024x1024). Run it twice and the output is byte-identical.
